Save Photos to Your Computer

Web browsers require a Secure Context (HTTPS or Localhost) to allow websites to directly browse your computer's local hard drive folders. Here are the 3 easiest ways to save and organize your photos:

1

Download as Named Folder ZIP (Recommended)

Type your preferred folder name in the Album folder name box and click Download ZIP. When you unzip, it automatically creates that exact folder with all photos inside!

2

Enable "Ask Where to Save" in Browser

In Chrome or Edge settings (chrome://settings/downloads), turn on "Ask where to save each file before downloading". Your computer will then prompt you to choose a folder on every download.

3

Connect via Local HTTPS

If the server host started the app with --ssl, open https://... in your browser to unlock the native folder selector on your computer.
